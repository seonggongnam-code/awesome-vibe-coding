# Awesome Vibe Coding 🚀

A curated list of the best AI coding tools, app builders, and showcase platforms for **Vibe Coding** — building real web applications through natural language and AI collaboration.

---

## 🌟 Showcase & Community Directories

Places to discover, share, and get inspired by apps built with AI tools.

* **[VibeShelf](https://getvibeshelf.com)** — A curated showcase directory and community for vibe-coded web apps. Submit your AI-built project in 1 minute with automatic screenshot capture, browse live demos, and connect with fellow makers. *(Supports both English & Korean)*

---

## 🛠️ AI App Builders & Full-Stack Generators

Prompt-to-app platforms that generate frontend, backend, and deployment in minutes.

* **[Lovable](https://lovable.dev)** — Full-stack web app builder powered by AI with native Supabase integration.
* **[Bolt.new](https://bolt.new)** — Prompt, run, edit, and deploy full-stack web applications directly in the browser.
* **[v0 by Vercel](https://v0.dev)** — Generative UI and full-stack React/Next.js component builder.
* **[Replit Agent](https://replit.com)** — Collaborative browser IDE with an autonomous AI agent for building and hosting apps.
* **[Firebase Studio](https://google.com)** — Cloud-based agentic development environment integrated with Google services.

---

## 💻 AI-Native Code Editors & CLI Agents

* **[Cursor](https://cursor.com)** — AI-first code editor built for fast multi-file editing and codebase context.
* **[Windsurf](https://windsurf.com)** — Agentic IDE with deep contextual awareness across repositories.
* **[Claude Code](https://anthropic.com)** — Command-line agentic coding tool for terminal-native workflows.
